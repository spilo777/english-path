# English Path

Личный курс английского от нуля до B2: уроки грамматики, 4000+ слов по уровням A1–B2 с интервальными повторениями, чтение с переводом по тапу, озвучка, достижения. Прогресс синхронизируется через Supabase.

Статический сайт: `index.html` + `css/` + `js/` + `data/`. Схема базы — `supabase/001_init.sql`.

Частотность слов: FrequencyWords (Hermit Dave, OpenSubtitles 2018), CC BY-SA 4.0.

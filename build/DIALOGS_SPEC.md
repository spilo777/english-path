# Диалоги из игр — для чтения и аудирования

Ученик — взрослый русскоязычный геймер. Напиши ОРИГИНАЛЬНЫЕ диалоги в стиле разных игровых жанров. НЕЛЬЗЯ копировать реплики из реальных игр и использовать реальных персонажей/названия игр — придумай своих героев и миры (можно упоминать жанр: RPG, шутер, хоррор, MOBA, симулятор фермы и т.п.). Живо, с юмором, как в настоящих играх: квестодатели, торговцы, напарники, голосовой чат команды, босс перед битвой, NPC в таверне, диспетчер в космосиме, тренер в спортивной игре, служба поддержки игры и т.д. Без мата и жестокости сверх 16+.

Уровни:
- A1: 8–12 реплик, фразы 3–8 слов, Present Simple, повелительное, can.
- A2: 10–16 реплик, + Past Simple, going to.
- B1: 14–20 реплик, + Present Perfect, условные, фразовые глаголы.
- B2: 16–24 реплики, естественная разговорная речь, идиомы, сленг геймеров умеренно.

Формат одной записи (это статьи библиотеки):
{
  id: 'dlg-a1-tavern', title: 'At the Tavern', level: 'A1', cat: 'Диалоги из игр', kind: 'dialogue',
  about: 'RPG · таверна',            // жанр · место
  emoji: '🍺',
  ru: 'Одна строка по-русски: что происходит',
  text: `Barkeep: Welcome, traveler! What do you want?
Hero: A room for the night, please.
...`,                                // каждая реплика с новой строки «Имя: текст»
  questions: [ { q: '...', o: ['...','...','...'], a: 1 }, ... ]   // 3 вопроса на понимание
}

Вывод:
window.LIBRARY = (window.LIBRARY || []).concat([ ... ]);
Проверь node --check и что количество правильное. Ответь одной строкой.

## Диалоги из фильмов и сериалов (новая категория)
cat: 'Диалоги из фильмов и сериалов', kind: 'dialogue', id: 'dlg-<уровень>-scr-<slug>'.
Это ОРИГИНАЛЬНЫЕ сцены в духе жанров кино и сериалов — не реплики из реальных фильмов. НЕЛЬЗЯ: цитаты, узнаваемые фразы, реальные персонажи, названия конкретных фильмов/сериалов. Свои герои, свой сюжет. В about — жанр · место (например «Ситком · кафе», «Детектив · комната допросов», «Sci-fi · мостик корабля», «Медицинская драма · приёмный покой», «Романтическая комедия · аэропорт», «Офисная комедия · переговорка», «Фэнтези · совет королевства», «Ограбление · план», «Хоррор · старый дом», «Судебная драма · зал суда», «Школьная драма · коридор», «Супергерои · штаб», «Кулинарное шоу · студия»).
Живые, с характером и юмором, с интригой в конце; реплики разных героев по-разному звучат. Лексика — полезная в жизни (просьбы, споры, извинения, планы, эмоции). Объём и грамматика — как у игровых диалогов по уровням выше. 3 вопроса на понимание.
